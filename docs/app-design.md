# gsword 桌面应用设计

- 状态：阶段 1–5 已实现（阅读器、研经工作区、个人内容、模块生态、进阶功能）
- 日期：2026-10-30
- 软件名称：`gsword`
- 基础库：`libgsword`
- UI 技术：GTK4 + libadwaita
- 目标平台：Linux/Unix 桌面，兼顾 Windows 和 macOS 的 GTK4 构建

---

## 1. 产品定位

`gsword` 是一款基于 `libgsword` 的现代 SWORD 研经桌面应用。

目标用户：

- 日常读经用户
- 需要多译本对照的研经用户
- 需要注释、词典、原文工具的用户
- 需要个人笔记、主题标签、祷告列表的用户
- 需要安装和管理 SWORD 模块的桌面用户

设计目标：

> 打开即读，选中即研经，随手可记，模块安装不打断阅读。

`gsword` 不是 Xiphos 的逐像素复刻，而是在 GTK4/Adwaita 基础上重新设计交互，
同时继承现有 SWORD 桌面应用的核心能力。

---

## 2. 从现有 SWORD 应用继承的能力

| 应用 | 继承点 |
|---|---|
| Xiphos | 个人注释、日记、祷告列表等可编辑内容 |
| BibleTime | 灵活的窗口布局，适合大量模块 |
| BibleDesktop | 多译本并行阅读，不受固定章节长度限制 |
| Alkitab | 注释、词典、字典、灵修统一到研经面板 |
| Ezra Bible App | 主题标签、经文列表、逐节笔记 |
| BibleCS | 简单直观的阅读入口 |
| FlashCards | 可选的背经和复习模式 |

设计原则：

1. **阅读优先**：启动后直接进入经文阅读。
2. **渐进式复杂**：默认界面简洁，高级能力通过侧栏和面板展开。
3. **资源联动**：经文、注释、词典、搜索、笔记共享当前经文位置。
4. **布局可保存**：阅读、研经、讲道、对照布局可保存为工作区。
5. **模块即资源**：安装、更新、删除模块不离开主窗口。
6. **离线优先**：本地模块和本地笔记优先，网络仅用于安装和更新。

## 4. 功能设计

### 4.1 核心阅读

- 圣经、注释书、词典、字典、通用书、每日灵修
- 书卷、章节、经文快速跳转
- 支持整章输入（如 `Genesis 1`、`启示录 1`、`来 1`）
- 阅读区始终显示完整章节
- 上一章/下一章、上一节/下一节
- 经文选择、复制、分享
- 脚注、交叉引用、标题、红字、Strong's、形态标签
- 阅读宽度、字体、行距、段落间距
- 亮色、暗色、跟随系统
- 当前经文高亮
- 阅读历史前进/后退

### 4.2 并行阅读

- 最多 4 个并行经文窗格
- 每个窗格可独立选择模块
- 支持同步滚动和独立滚动
- 支持同步当前经文光标
- 支持 passage 阅读，而不是强制按章节
- 支持锁定窗格
- 支持保存为对照工作区

### 4.3 研经面板

右侧统一研经面板，包含：

- 注释 Commentary
- 词典 Dictionary
- 字典 Lexicon
- 交叉引用 Crossrefs
- 原文/Strong's
- 笔记 Notes
- 相关经文

点击 Strong's 编号、脚注或交叉引用时，研经面板自动切换到对应资源。

### 4.4 搜索

- phrase
- multiword
- regex
- 大小写敏感
- 指定模块
- 指定书卷/章节范围
- 属性搜索，例如 `Word/Lemma=G26`
- 持久化倒排索引
- 索引进度、取消、删除
- 搜索结果按模块分组
- 结果预览、跳转、加入经文列表

### 4.5 笔记与个人内容

- 个人注释
- 逐节笔记
- 日记/灵修笔记
- 祷告列表
- 主题标签
- 经文高亮
- 经文列表/收藏夹
- 笔记搜索
- 导出 Markdown/HTML

存储策略：

- 个人注释：RawFiles / Personal Commentary
- 日记、祷告列表、通用笔记：RawGenBook
- 阅读计划、计划进度、背经队列、教学笔记：SQLite `app.db`
- 标签、工作区、界面状态：SQLite / GSettings

优先使用 SWORD 兼容格式，使笔记可被其他 SWORD 应用读取。

### 4.6 模块库与安装

- 本地模块列表
- 已安装、可更新、未安装状态
- 远程源管理
- 按名称、语言、类型、授权过滤
- 模块详情：
  - 描述、版本、大小、语言、授权
  - 模块类型
  - 安装状态
  - 依赖/冲突
- 下载进度、速度、剩余时间、取消
- 安装完成后刷新模块库
- 删除模块前确认
- 本地目录安装

### 4.7 阅读计划与灵修

- 每日灵修模块
- 读经计划
- 计划进度
- 今日阅读
- 连续阅读天数
- 提醒设置

### 4.8 背经与复习

可选功能：

- 经文卡片
- 遮盖单词
- 首字母提示
- 间隔重复
- 每日复习队列
- 输入测验
- 希腊文/希伯来文键盘输入

### 4.9 导出与打印

- 复制经文和出处
- 纯文本、HTML、Markdown
- 导出搜索结果
- 打印当前 passage
- 导出笔记

## 7. 响应式与无障碍

### 宽屏

```text
侧栏 + 阅读区 + 研经面板
```

### 中等宽度

```text
侧栏 + 阅读区
研经面板折叠为侧页
```

### 窄屏/平板

```text
顶栏 + 阅读区
书卷导航和研经面板通过抽屉打开
```

使用 `AdwNavigationSplitView` 的 collapsed 状态自动适应。

无障碍要求：

- 完整键盘操作
- 屏幕阅读器标签
- 高对比度模式
- 可调字体大小、行距、阅读宽度
- RTL 支持
- 本地化书名和缩写
- 经文原文语言字体回退

## 9. GTK4 与 libgsword 映射

| 功能 | libgsword 能力 |
|---|---|
| 模块列表 | `GswManager` |
| 经文读取 | `GswModule` |
| 书卷跳转 | `GswVerseKey` |
| 并行阅读 | 多个独立 `GswModule` 实例 |
| 搜索 | `GswSearchOptions` / `GswSearchResult` |
| 搜索索引 | `gsw_module_build_search_index()` |
| 注释/词典 | 独立模块 + 当前 key 联动 |
| 笔记 | RawFiles / RawGenBook |
| 模块安装 | `GswInstallManager` |
| 安装进度 | `GswStatusReporter` |
| 本地化 | `GswLocaleMgr` |

渲染建议：

- 经文区使用 WebKitGTK 6.0 渲染 `gsw_module_get_render_html()`；
- 笔记使用 `GtkTextView` 或 `GtkSourceView`；
- 搜索结果使用 `GtkListView` + `GtkFilterListModel`；
- 长任务使用 GTask，配合 `GCancellable` 和进度回调。

## 10. 状态与数据存储

```text
~/.local/share/gsword/          SWORD 模块库
~/.local/share/gsword-app/      应用私有状态
  ├── app.db                    SQLite：标签、收藏、工作区
  ├── exports/                  导出文件
  └── cache/                    HTML、搜索结果缓存
```

原则：

- 模块内容不复制到应用数据库；
- 笔记优先写入 SWORD 兼容模块；
- 标签、工作区、界面状态属于应用私有数据；
- 设置使用 GSettings；
- 写操作异步执行，避免阻塞 UI。

## 12. 验收标准

- 冷启动后 3 秒内显示可读经文；
- 10 万条以上搜索可通过索引在可接受时间内完成；
- 并行阅读 2–4 个模块时滚动和跳转保持同步；
- 笔记写入失败不破坏既有模块和笔记；
- 模块安装支持进度、取消和失败清理；
- 键盘可完成阅读、搜索、跳转、笔记和安装主流程；
- 窄窗口下仍可完成阅读和搜索；
- 中英文界面和本地化书名/缩写正常显示。
