# gsword 桌面应用设计

- 状态：阶段 1–10 已实现（阅读器、研经工作区、个人内容、模块生态、进阶功能；
  窗口已按页面对象重构，主导航使用 AdwHeaderBar + AdwViewSwitcher 自适应布局）
- 日期：2026-11-01
- 软件名称：`gsword`
- 基础库：`libgsword`
- UI 技术：GTK4 + libadwaita
- 目标平台：Linux/Unix 桌面，兼顾 Windows 和 macOS 的 GTK4 构建

---

## 1. 产品定位

`gsword` 是一款基于 `libgsword` 的现代 SWORD 研经桌面应用。

目标用户：

- 日常读经用户
- 需要多译本对照的研经用户
- 需要注释、词典、原文工具的用户
- 需要个人笔记、主题标签、祷告列表的用户
- 需要安装和管理 SWORD 模块的桌面用户

设计目标：

> 打开即读，选中即研经，随手可记，模块安装不打断阅读。

`gsword` 不是 Xiphos 的逐像素复刻，而是在 GTK4/Adwaita 基础上重新设计交互，
同时继承现有 SWORD 桌面应用的核心能力。

---

## 2. 从现有 SWORD 应用继承的能力

| 应用 | 继承点 |
|---|---|
| Xiphos | 个人注释、日记、祷告列表等可编辑内容 |
| BibleTime | 灵活的窗口布局，适合大量模块 |
| BibleDesktop | 多译本并行阅读，不受固定章节长度限制 |
| Alkitab | 注释、词典、字典、灵修统一到研经面板 |
| Ezra Bible App | 主题标签、经文列表、逐节笔记 |
| BibleCS | 简单直观的阅读入口 |
| FlashCards | 可选的背经和复习模式 |

设计原则：

1. **阅读优先**：启动后直接进入经文阅读。
2. **渐进式复杂**：默认界面简洁，高级能力通过侧栏和面板展开。
3. **资源联动**：经文、注释、词典、搜索、笔记共享当前经文位置。
4. **布局可保存**：阅读、研经、讲道、对照布局可保存为工作区。
5. **模块即资源**：安装、更新、删除模块不离开主窗口。
6. **离线优先**：本地模块和本地笔记优先，网络仅用于安装和更新。

## 3. 目录与工程边界

```text
libsword/
├── include/gsword/      # libgsword 公共 API
├── lib/                 # libgsword 实现
├── src/                 # gsword GTK4 应用
├── docs/
│   ├── design.md        # 库设计
│   ├── app-design.md    # 本文档
│   ├── formats.md
│   └── upstream-analysis.md
├── examples/            # 库示例和 GTK4 原型
└── tests/               # 库测试
```

应用层只依赖 `include/gsword/` 的公共接口。`lib/` 中的私有头文件不应被
`src/` 直接包含，除非有明确记录的内部边界。

应用窗口采用页面对象装配：`src/window.c` 只保留窗口壳体、页面注册、
菜单/快捷键、共享服务和跨页面协调；各页面拥有自己的控件、回调和局部状态，
通过 `src/window-private.h` 的窄接口访问窗口能力。页面拆分与验收记录见
`docs/window-refactor-plan.md` 和 `docs/window-refactor-acceptance.md`。

## 4. 功能设计

### 4.1 核心阅读

- 圣经、注释书、词典、字典、通用书、每日灵修
- 书卷、章节、经文快速跳转
- 支持整章输入（如 `Genesis 1`、`启示录 1`、`来 1`）
- 阅读区始终显示完整章节
- 上一章/下一章、上一节/下一节
- 经文选择、复制、分享
- 脚注、交叉引用、标题、红字、Strong's、形态标签
- 阅读宽度、字体、行距、段落间距
- 亮色、暗色、跟随系统
- 当前经文高亮
- 切换圣经版本时保持当前书卷、章、节；如果新版本没有该经文，则回到同一书卷的首章首节
- 阅读历史前进/后退、最近阅读列表，最多保留 50 条并跨重启保存
- `Alt+Left` / `Alt+Right` 快速返回和前进

### 4.2 并行阅读

- 最多 4 个并行经文对照栏
- 每个对照栏可独立选择圣经译本，非经文模块不出现在下拉列表中
- 支持同步滚动和独立滚动
- 支持同步当前经文光标
- 支持 passage 阅读，而不是强制按章节
- 支持锁定对照栏
- 支持保存为对照工作区

### 4.3 研经面板

右侧统一研经面板，包含：

- 注释 Commentary
- 词典 Dictionary
- 字典 Lexicon
- 交叉引用 Crossrefs
- 原文/Strong's
- 笔记 Notes
- 相关经文

点击 Strong's 编号、脚注或交叉引用时，研经面板自动切换到对应资源。

### 4.4 搜索

- phrase、multiword、regex 三种文本搜索
- 大小写敏感选项
- 选择要搜索的模块；搜索结果使用独立的模块实例，不移动阅读器位置
- 范围：整个模块、旧约、新约、当前书卷、当前章节
- 属性搜索，例如 `Word/Lemma=G26`
- 搜索异步执行，带进度、取消和结果计数；失败或取消时保留上一轮结果
- 持久化倒排索引；状态栏说明当前查询是否使用索引，可建立/删除所选模块的索引
- 最近搜索历史
- 结果预览中的匹配词高亮、结果跳转

### 4.5 笔记与个人内容

- 个人注释
- 逐节笔记
- 日记/灵修笔记
- 祷告列表
- 主题标签
- 经文高亮
- 经文列表/收藏夹
- 笔记搜索、标签筛选和按更新时间排序
- 笔记自动保存、未保存状态提示和删除确认
- 笔记编辑时显示对应经文的单节预览
- Markdown 源文本编辑、基础格式工具栏和语法高亮
- 从预览直接跳回阅读器
- 经文列表增删、列表经文选择和移除；阅读器工具栏可直接把当前经文加入/移出列表
- 导出 Markdown/HTML

存储策略：

- 个人注释：RawFiles / Personal Commentary
- 日记、祷告列表、通用笔记：RawGenBook
- 阅读计划、计划进度、背经队列、教学讲义：SQLite `app.db`
- 标签、工作区、界面状态：SQLite / GSettings

优先使用 SWORD 兼容格式，使笔记可被其他 SWORD 应用读取。

### 4.6 模块库与安装

- 本地模块列表
- 已安装、可更新、未安装状态
- 远程源管理
- 按名称、语言、类型、授权过滤
- 模块详情：
  - 描述、版本、大小、语言、授权
  - 模块类型
  - 安装状态
  - 依赖/冲突
- 下载进度、速度、剩余时间、取消
- 安装完成后刷新模块库
- 删除模块前确认
- 本地目录安装

### 4.7 阅读计划与灵修

- 每日灵修模块
- 读经计划
- 计划进度
- 今日阅读
- 连续阅读天数
- 提醒设置

### 4.8 背经与复习

可选功能：

- 经文卡片
- 遮盖单词
- 首字母提示
- 间隔重复
- 每日复习队列
- 输入测验
- 希腊文/希伯来文键盘输入

### 4.9 导出与打印

- 复制经文和出处
- 纯文本、HTML、Markdown
- 导出搜索结果
- 打印当前 passage
- 导出笔记

## 6. 主界面设计

### 6.1 主窗口

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 阅读  对照  笔记  计划  模块库              [搜索] [菜单]        │
├──────────────┬─────────────────────────────────────┬─────────────────┤
│ 书卷导航      │  Genesis 1:1                        │ 研经面板         │
│              │                                     │                 │
│ 旧约          │  1 起初，神创造天地。                │ [注释][词典]     │
│  ˅ 创世记     │  2 地是空虚混沌...                   │ [原文][笔记]     │
│  ˅ 出埃及记   │  3 神说：要有光...                   │                 │
│  ˅ 利未记     │                                     │ 当前经文注释     │
│              │                                     │ ...             │
│ 新约          │                                     │                 │
│  ˅ 马太福音   │                                     │                 │
│  ˅ 马可福音   │                                     │                 │
├──────────────┴─────────────────────────────────────┴─────────────────┤
│ KJV ▾  |  创世记 1:1  |  索引: 已建立  |  阅读计划: 第 12 天          │
└──────────────────────────────────────────────────────────────────────┘
```

推荐 GTK4 组件：

- `AdwApplicationWindow`
- `AdwToolbarView`
- `AdwHeaderBar`
- `AdwViewStack`
- `AdwViewSwitcher`
- `AdwViewSwitcherBar` + `AdwBreakpoint`（窄窗口底部导航）
- `AdwOverlaySplitView`（可隐藏/覆盖式模块侧栏）
- `AdwToastOverlay`
- `GtkPaned`
- `GtkListView`
- `GtkPopover`
- `WebKitWebView` 作为经文渲染区

主导航采用单行标题栏布局：宽窗口在 `AdwHeaderBar` 中显示
`AdwViewSwitcher`。窗口最小宽度为 1100px，正常情况下不会进入底部导航模式；
若系统或窗口管理器强制缩窄到 `700sp` 以下，则隐藏标题栏导航并改用底部
`AdwViewSwitcherBar` 作为降级布局。模块侧栏与内容区都从标题栏下方开始。

搜索不再是顶层导航项，而是标题栏右侧的搜索按钮和 `Ctrl+F` 动作；搜索页
仍保留完整搜索界面和索引管理，并提供返回按钮。

模块侧栏使用 `AdwOverlaySplitView`。宽窗口下可通过标题栏左侧按钮或 `F9`
隐藏/显示；隐藏后内容占满宽度。窄窗口下侧栏变为覆盖层，默认关闭，选择模块
后自动收起。宽窗口的侧栏可见状态由 `sidebar-visible` GSettings 键保存。

```text

│ [KJV ▾]  [Gen 1:1 ▾]  ← →   [同步]   [布局]   [书签]      │
├────────────────────────────────────────────────────────────┤
│ Genesis 1                                                  │
│                                                            │
```

- 点击 Strong's：打开字典
- 点击脚注/交叉引用：打开对应资源

### 6.5 搜索页面

```text
┌──────────────────────────────────────────────────────────────┐
│ [返回] 搜索：[ love                    ] [历史] [搜索] [取消]│
│ 模块：[KJV ▾]   范围：[整个模块 ▾]                           │
│ 类型：[短语 ▾]  [ ] 区分大小写  [建立索引] [删除索引]        │
│ ▸ 高级：属性 1 [Word]   属性 2 [Lemma]                       │
│ 索引：已建立（本次搜索使用）                                  │
├──────────────────────────────────────────────────────────────┤
│ 搜索：2 个结果                                                │
│ Genesis 1:1                                                   │
│ God is **love**                                               │
│ Genesis 1:3                                                   │
│ **love** your neighbour                                       │
└──────────────────────────────────────────────────────────────┘
```

搜索页是内部页面，由标题栏搜索按钮或 `Ctrl+F` 打开，返回按钮回到打开前的
页面。候选模块来自模块库，打开搜索页时默认选中当前阅读模块；范围以当前阅读
位置为基准。索引仅用于不区分大小写、
未限定范围且未启用属性过滤的 phrase/multiword 查询；其他查询自动回退到扫描，
状态行会明确说明。最近搜索保存在当前会话内，可从搜索框右侧的历史按钮重新执行。

### 6.6 笔记与标签

```text
┌──────────────────────────────────────────────────────────────┐
│ 笔记 | 标签 | 经文列表                                        │
├────────────────────────┬─────────────────────────────────────┤
│ 搜索笔记               │ 创世记 1:1               已保存      │
│ 创世记 1:1             │ TinySearch · 创世记 1:1  在阅读器中打开│
│ God is love...         │                                     │
│ 救恩, 神的爱  11-03    │ God is love                         │
│ 创世记 1:2             │                                     │
│ 神创造世界...          │ 标签：救恩, 神的爱        [+]        │
│                        │                                     │
│                        │ Markdown 编辑器                     │
│                        │                                     │
│                        │ [保存] [删除] [加入列表 ▾] [导出]    │

```

左侧用分页代替纵向堆叠，避免笔记、标签、列表和列表经文互相挤压：

- **笔记**：搜索、标签筛选、笔记列表；显示经文引用、两行预览、标签和更新时间。
- **标签**：单击标签过滤笔记列表；通过标签菜单显式添加到当前笔记。
- **经文列表**：列表名称与列表经文分成上下两个区域；可选中列表经文后打开或移除。
- 编辑区在停止输入约 1 秒后自动保存，并显示“已保存 / 有未保存的更改 / 未保存”。
- “加入列表”显示带勾选框的列表菜单；阅读器工具栏也提供同样的当前经文列表菜单。

```text
│ KJV King James Version                                       │

```

类型、语言、安装状态和文本搜索可以组合使用，只显示同时满足所有条件
的模块；筛选行右侧显示当前结果数量。语言选项根据当前安装源动态生成，
常见语言显示“中文 (zh)”“英文 (en)”等名称，未知语言显示原始代码。

模块详情显示描述、类型、语言、版本、格式化后的大小、安装源、许可和
安装状态；本地与远程版本不同时显示版本对比。驱动、编码、章节体系、
最低 SWORD 版本、模块 ID 和路径放入“详细信息”折叠区，版权/许可和
About 使用独立折叠区，避免技术信息挤占主要阅读空间。

安装过程中显示进度、速度、剩余时间、取消按钮，完成后用 toast 提示。

## 7. 响应式与无障碍

### 宽屏

```text
侧栏 + 阅读区 + 研经面板
```

### 中等宽度

```text
侧栏 + 阅读区
研经面板折叠为侧页
```

### 窄屏/平板

```text
顶栏 + 阅读区
书卷导航和研经面板通过抽屉打开
```

使用 `AdwOverlaySplitView` 的 collapsed 状态自动适应，并提供覆盖式模块侧栏。

无障碍要求：

- 完整键盘操作
- 屏幕阅读器标签
- 高对比度模式
- 可调字体大小、行距、阅读宽度
- RTL 支持
- 本地化书名和缩写
- 经文原文语言字体回退

## 10. 状态与数据存储

```text
~/.local/share/gsword/          模块库和应用私有状态
  ├── mods.d/                   模块配置
  ├── modules/                  模块数据
  ├── app.db                    SQLite：笔记、计划、背经、教学讲义
  ├── installmgr/               安装源和下载缓存
  ├── exports/                  导出文件
  └── cache/                    HTML、搜索结果缓存
```

首次启动时会自动把旧版 `~/.local/share/gsword-app` 中的 `app.db` 和
`installmgr/` 迁移到 `~/.local/share/gsword`；新目录已存在时保留新文件，
缺失的文件从旧目录补齐。

原则：

- 模块内容不复制到应用数据库；
- 笔记优先写入 SWORD 兼容模块；
- 标签、工作区、界面状态属于应用私有数据；
- 设置使用 GSettings；
- 写操作异步执行，避免阻塞 UI。
