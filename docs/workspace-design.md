# gsword 阅读工作区与多资源协同设计

- 状态：阶段 A–D 完成
- 日期：2026-10-31
- 范围：`src/` 中的 GTK4/libadwaita 应用

## 1. 问题背景

当前 `gsword` 存在两个结构性问题：

1. 模块列表基本是平铺的，没有按资源类型组织；
2. 阅读区显示整章，但缺少明确的“当前活动节”，注释、词典和交叉引用只能隐式依赖当前模块 key。

结果是：

- 用户滚动阅读整章时，无法确认注释对应哪一节；
- 注释可能仍停留在旧位置，或者因为章节 key 不包含节号而对应到第 1 节；
- 圣经、注释、词典、通用书籍、地图、灵修同时使用时互相替换页面；
- 地图、通用书等资源被错误地当作章节文本处理；
- 多窗格对照和固定注释位置无法表达。

根因不是单一的注释模块选择错误，而是缺少稳定的 **Passage Context（活动段落上下文）** 和 **资源 Viewer 模型**。

## 2. 设计目标

1. 以活动经文作为全局唯一状态源。
2. 模块是资源，不再等同于页面。
3. 不同类型模块使用不同 Viewer。
4. 阅读、注释、词典、地图、通用书、笔记可以同时打开。
5. 每个资源窗格支持“跟随活动经文”和“固定位置”。
6. 界面始终显示当前完整引用，例如 `KJV · Genesis 1:5`。
7. 工作区布局可保存和恢复。

## 3. 核心模型

### 3.1 Passage Context

```text
Bible module
canonical OSIS reference (e.g. Gen.1.5)
book / chapter / active verse
optional active range
optional word / Strong's token
```

内部使用 OSIS 引用作为规范位置，避免直接保存某个模块的书名显示文本。每个模块需要 key 时，再按自己的 versification 转换。

### 3.2 Resource

```text
module name
module type
driver
viewer capability
```

示例：

| 类型 | 典型驱动 | Viewer |
|---|---|---|
| Bible | RawText/zText | 章节阅读器 |
| Commentary | RawCom/zCom | 按节注释器 |
| Lexicon/Dictionary | RawLD/zLD | 词条查询器 |
| Daily Devotion | RawLD/zLD + DailyDevotion | 日期灵修器 |
| General Book | RawGenBook | 目录树 + 正文 |
| Map | 文件资源 | 地图/图片查看器 |
| Notes | 应用数据库 | 个人内容编辑器 |

### 3.3 Pane

```text
resource
viewer type
follow mode: FOLLOW | PINNED | FREE
current key
split position
```

`FOLLOW` 窗格跟随 Passage Context；`PINNED` 窗格保留用户固定位置；`FREE` 窗格完全独立。

### 3.4 Workspace

工作区保存窗格集合、方向、尺寸、活动窗格和当前 Passage Context。建议持久化到 SQLite；早期可以先用 GSettings 保存简化布局。

## 4. 界面结构

```text
┌────────────────────────────────────────────────────────────┐
│ gsword   [阅读] [窗格] [搜索] [笔记] [计划] [模块库]        │
├──────────────┬──────────────────────────────┬──────────────┤
│ 资源库        │ 阅读工作区                    │ 研经坞        │
│              │                              │              │
│ 圣经          │ KJV · Genesis 1:5            │ 注释          │
│ 注释书        │ 1 ...                        │ Matthew Henry │
│ 词典/字典     │ 2 ...                        │ Genesis 1:5   │
│ 灵修          │ 3 ...                        │              │
│ 通用书籍      │ 4 ...                        │ 词典          │
│ 地图          │ 5 ... ← 当前节高亮           │ 交叉引用       │
│ 个人内容      │                              │ 笔记          │
└──────────────┴──────────────────────────────┴──────────────┘
```

### 4.1 左侧资源库

按类型分组，提供：

- 打开到当前窗格
- 打开到新窗格
- 固定到研经坞
- 查看模块信息

### 4.2 多窗格工作区

“窗格”页提供可编辑多窗格工作区：

- “添加窗格”创建新的资源窗格；
- 每个窗格可选择模块、输入引用、切换跟随模式；
- 拖动窗格标题栏的拖动手柄到另一个窗格可交换位置；
- 关闭按钮删除单个窗格，“清空窗格”删除全部窗格；
- 列数可在 1–4 之间调整；
- “同步滚动”可让多个窗格共享垂直滚动位置；
- 窗格布局、模块、引用、跟随状态、列数和同步滚动写入 GSettings；
- 点击 Bible 窗格中的经文会更新所有 FOLLOW 窗格。

“并行工作区”不再维护独立页面，而是“窗格”的模板：

- 创建两个 Bible 窗格；
- 使用相同的当前经文；
- 两个窗格都启用跟随；
- 启用同步滚动；
- 列数设为 2。

应用并行模板会重新创建窗格布局，当前窗格会被替换。旧版本的
`parallel-a`、`parallel-b` 设置会用于初始化该模板；旧的
`active-page = parallel` 会自动迁移到 `panes`。

### 4.3 阅读上下文栏

始终显示模块和完整引用：

```text
[KJV] [Genesis] [1] [:5]  [上一节] [下一节]
KJV · Genesis 1:5
```

章节导航和逐节导航分离：

- 上一章/下一章改变章；
- 上一节/下一节改变活动节；
- 章变化时活动节默认重置为 1；
- 输入 `Genesis 1:5` 时明确设置活动节。

### 4.4 逐节交互

整章阅读必须支持逐节选中：

- 每节有稳定 anchor；
- 点击某节设置活动节并高亮；
- 活动节写入顶部引用和状态栏；
- 活动节变化触发注释、词典、交叉引用更新；
- `Shift + 单击` 扩展经文范围，锚点节作为活动节和范围起点；
- 范围高亮、状态栏和顶部引用显示 `书卷 章:起-止`；
- 范围同步时，注释和 FOLLOW 窗格使用范围起点。

初版可以继续使用 `GtkTextView`，建立节号到文本行的映射；后续可以考虑 `GtkListView` 或 WebKit DOM anchor。

## 5. 注释对齐设计

注释必须绑定活动节，而不是章节级 key 或当前模块的显示文本。

数据流：

```text
点击 Genesis 1:5
  → Passage Context 更新为 Gen.1.5
  → passage-changed
  → FOLLOW 注释窗格收到 Gen.1.5
  → 按注释模块 versification 转换
  → 读取对应节注释
```

注释窗格必须显示：

```text
Matthew Henry
Genesis 1:5
```

没有条目时显示明确空状态，不能保留上一节内容。注释窗格提供“跟随 / 固定”。

注释查找顺序：

1. 精确节级条目；
2. 章节引言或章节级条目；
3. 相邻节提示；
4. 明确显示没有注释。

不同 versification 之间通过 OSIS 书卷、章、节映射，不直接复制 key text。

## 6. 类型化 Viewer

### Bible

- 整章阅读；
- 活动节高亮；
- 逐节导航；
- 并行窗格；
- 复制当前节、范围、整章。

### Commentary

- 默认在研经坞；
- 按活动节加载；
- 可固定；
- 显示模块名和完整引用；
- 无条目明确提示。

### Lexicon / Dictionary

- 词条查询视图；
- Strong's/原文词跳转；
- 显示当前查询词和词典模块；
- 不显示章节阅读界面。

### Daily Devotion

- 独立按日期显示；
- 不跟随圣经章节；
- 有模块和日期选择。

### General Book

- 目录树/章节树；
- 正文查看；
- 独立当前位置。

### Map

- 图片/地图查看器；
- 缩放、平移、图例；
- 可选热点和经文关联；
- 无 Viewer 时显示资源信息和不可用提示，不能当文本读取。

### Notes

- 当前节笔记；
- 当前范围笔记；
- 独立笔记文档；
- 标签、经文列表、阅读计划归入个人内容。

## 7. 工作区与持久化

建议模板：

- Reading：Bible
- Study：Bible + Commentary + Lexicon
- Parallel：Bible + Bible
- Teaching：Bible + Teaching Notes + Commentary
- Map Study：Bible + Map

保存内容：

- 窗格资源；
- follow/pin 模式；
- 分割方向和大小；
- 活动 Bible 模块；
- OSIS 引用和活动节。

## 8. 实施阶段

### 阶段 A：活动节与注释对齐

- [x] Passage Context（以模块 VerseKey 维护当前活动节）
- [x] 阅读区活动节高亮
- [x] 点击经文选择活动节
- [x] 完整引用显示（工具栏、状态栏、key 输入框）
- [x] 注释按活动节加载
- [x] 注释头部显示模块和引用
- [x] 注释无条目明确提示

实现说明：

- 阅读区仍使用 `GtkTextView` 显示整章，通过文本行 verse anchor 建立节选择；
- 活动节使用独立文本 tag 高亮；
- 章节切换时活动节重置为第 1 节；
- 点击经文后只更新活动节和研经面板，不重建整章，避免滚动位置跳动；
- 注释标题显示 `模块名 — 书卷 章:节`。

### 阶段 B：资源分组和多窗格

- [x] 左侧资源按类型分组
- [x] 资源按类型路由：Bible → 阅读窗格；Commentary / Lexicon → 研经窗格；Devotion → 灵修页
- [x] 跟随/固定模式
- [x] Bible + Commentary 双窗格
- [x] 研经面板可见性、注释模块、词典模块、跟随状态和固定位置持久化
- [x] 固定阅读窗格 + 研经窗格
- [x] 独立的可编辑多窗格工作区（窗格页）

实现说明：

- 阅读页保留固定的“阅读窗格 + 研经窗格”布局，先保证圣经和注释可以同时使用；
- 新增“窗格”页作为可编辑多窗格工作区；
- 点击注释模块不会替换圣经阅读区，而是切换研经窗格的注释来源；
- 点击词典模块切换研经窗格的词典来源；
- 点击每日灵修模块跳到“计划 → 灵修”；
- 地图模块打开资源 Viewer，从 RawGenBook 条目中解析并显示图片资源；
- 注释的“跟随”关闭后，会保存当前注释引用，阅读区继续翻章不会改变注释位置。

### 阶段 C：类型化 Viewer

- [x] 词典查询 Viewer（模块选择、查询、结果展示）
- [x] 通用书籍树 Viewer（树条目浏览、正文显示）
- [x] 每日灵修日期 Viewer（前一天、今天、后一天）
- [x] 地图 Viewer（RawGenBook 地图资源图片显示，文本回退）
- [x] 笔记与活动经文关联（复用现有逐节笔记和经文列表流程）

实现说明：

- 通用书籍和地图使用隐藏的 `resource` 工作区，不占用主阅读窗格的 Bible 上下文；
- 地图 Viewer 从 RawGenBook 条目中解析 `<img src="...">`，按模块数据目录解析图片路径；
- 词典页增加模块下拉框，并从侧栏选择词典时同步；
- 灵修页支持按日期前后切换；
- 笔记仍通过当前活动经文打开和保存，沿用既有 SQLite 笔记库。

### 阶段 D：高级协同

- [x] Strong's/词典联动（Strong's 列表点击后进入词典页查询）
- [x] 交叉引用跳转（交叉引用列表点击后打开对应经文）
- [x] 范围同步（Shift + 单击选择范围，起点同步注释和 FOLLOW 窗格）
- [x] 教学工作区（工作区模板 + 教学布局）
- [x] 工作区模板（阅读、研经、并行、教学、多窗格）
- [x] 任意创建/拖拽/编辑多个窗格
- [x] 并行模板复用窗格实现，不再维护独立并行页面

实现说明：

- Strong's 页现在由可点击的 Strong's 编号列表和原文字段正文组成；
- 交叉引用页按分号拆分引用，点击条目返回阅读器对应位置；
- 主菜单提供阅读、研经、多窗格、并行和教学工作区模板；
- “并行工作区”现在只是“窗格”的两列 Bible 模板，自动启用跟随和同步滚动；
- “窗格”页支持任意添加、删除、编辑模块和引用，拖动手柄交换窗格顺序，1–4 列布局；
- 窗格布局以 `workspace-layout` 和 `workspace-columns` 持久化；
- Shift + 单击选择经文范围，范围高亮和状态栏显示完整范围，注释及 FOLLOW 窗格按范围起点同步；
- 复制按钮在范围激活时只复制范围内经文。

## 9. 验收标准

1. 阅读整章时活动节有明确高亮。
2. 顶部显示 `模块 · 书卷 章:节`。
3. 点击不同经文，注释立即切换。
4. 注释显示自己的模块名和引用。
5. 注释无条目时显示明确提示。
6. 注释可固定，不被翻章打断。
7. 圣经和注释可同时显示。
8. 词典、通用书、灵修、地图不会按章节文本处理。
9. 资源可打开到当前窗格、新窗格或研经坞。
10. 工作区布局重启后可恢复。
11. 多窗格工作区可添加、删除、编辑、拖拽重排并恢复。
12. Shift + 单击可选择经文范围并同步研经面板和 FOLLOW 窗格。
13. 并行入口创建两个同步滚动的 Bible 窗格，不再有独立并行页面。
14. 旧 parallel 页面设置可迁移到窗格模板。
