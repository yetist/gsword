# GSword 桌面应用设计

- 状态：阶段 1–10 已实现（阅读器、研经工作区、个人内容、模块生态、进阶功能；
  窗口已按页面对象重构，主导航使用 AdwHeaderBar + AdwViewSwitcher 自适应布局；
  个人中心首版已实现，主导航收敛为阅读、对照、个人）
- 日期：2026-11-01
- 软件名称：GSword
- 源码仓库：<https://github.com/yetist/gsword>
- 基础库：`libgsword`
- UI 技术：GTK4 + libadwaita
- 目标平台：Linux/Unix 桌面，兼顾 Windows 和 macOS 的 GTK4 构建

---

## 1. 产品定位

GSword 是一款基于 `libgsword` 的现代研经桌面应用。

目标用户：

- 日常读经用户
- 需要多译本对照的研经用户
- 需要注释、词典、原文工具的用户
- 需要个人笔记、主题标签、祷告列表的用户
- 需要安装和管理 SWORD 模块的桌面用户

设计目标：

> 打开即读，选中即研经，随手可记，模块安装不打断阅读。

GSword 不是 Xiphos 的逐像素复刻，而是在 GTK4/Adwaita 基础上重新设计交互，
同时继承现有 SWORD 桌面应用的核心能力。

---

## 2. 从现有 SWORD 应用继承的能力

| 应用 | 继承点 |
|---|---|
| Xiphos | 个人注释、日记、祷告列表等可编辑内容 |
| BibleTime | 灵活的窗口布局，适合大量模块 |
| BibleDesktop | 多译本并行阅读，不受固定章节长度限制 |
| Alkitab | 注释、词典、字典、灵修统一到研经面板 |
| Ezra Bible App | 主题标签、经文列表、逐节笔记 |
| BibleCS | 简单直观的阅读入口 |
| FlashCards | 可选的背经和复习模式 |

设计原则：

1. **阅读优先**：启动后直接进入经文阅读。
2. **渐进式复杂**：默认界面简洁，高级能力通过侧栏和面板展开。
3. **资源联动**：经文、注释、词典、搜索、笔记共享当前经文位置。
4. **布局可保存**：阅读、研经、讲道、对照布局可保存为工作区。
5. **模块即资源**：安装、更新、删除模块不离开主窗口。
6. **离线优先**：本地模块和本地笔记优先，网络仅用于安装和更新。

## 3. 目录与工程边界

```text
libsword/
├── include/gsword/      # libgsword 公共 API
├── lib/                 # libgsword 实现
├── src/                 # gsword GTK4 应用
├── docs/
│   ├── design.md        # 库设计
│   ├── app-design.md    # 本文档
│   ├── formats.md
│   └── upstream-analysis.md
├── examples/            # 库示例和 GTK4 原型
└── tests/               # 库测试
```

应用层只依赖 `include/gsword/` 的公共接口。`lib/` 中的私有头文件不应被
`src/` 直接包含，除非有明确记录的内部边界。

应用窗口采用页面对象装配：`src/window.c` 只保留窗口壳体、页面注册、
菜单/快捷键、共享服务和跨页面协调；各页面拥有自己的控件、回调和局部状态，
通过 `src/window-private.h` 的窄接口访问窗口能力。页面拆分与验收记录见
`docs/window-refactor-plan.md` 和 `docs/window-refactor-acceptance.md`。

## 4. 功能设计

### 4.1 核心阅读

- 圣经、注释书、词典、字典、通用书、每日灵修
- 书卷、章节、经文快速跳转
- 支持整章输入（如 `Genesis 1`、`启示录 1`、`来 1`）
- 阅读区始终显示完整章节
- 上一章/下一章、上一节/下一节
- 经文选择、复制、分享
- 脚注、交叉引用、标题、红字、Strong's、形态标签
- 阅读宽度、字体、行距、段落间距
- 亮色、暗色、跟随系统
- 当前经文高亮
- 切换圣经版本时保持当前书卷、章、节；如果新版本没有该经文，则回到同一书卷的首章首节
- 阅读历史前进/后退、最近阅读列表，最多保留 50 条并跨重启保存
- `Alt+Left` / `Alt+Right` 快速返回和前进
- 书卷名称语言可跟随模块或跟随界面；正文字体可选无衬线/衬线
- 模块库位置可在偏好设置中查看、打开或更改；检测到旧 `~/.sword` 时可显式切换

### 4.2 并行阅读

- 最多 4 个并行经文对照栏
- 每个对照栏可独立选择圣经译本，非经文模块不出现在下拉列表中
- 支持同步滚动和独立滚动
- 支持同步当前经文光标
- 支持 passage 阅读，而不是强制按章节
- 支持跟随、固定、独立三种对照模式，并高亮当前活动对照栏
- 支持按节同步滚动、缺失经节提示和可选的差异高亮
- 支持两译本/四译本对照模板和保存布局

### 4.3 研经面板

右侧统一研经面板，包含：

- 注释 Commentary
- 词典 Dictionary
- 字典 Lexicon
- 交叉引用 Crossrefs
- 原文/Strong's
- 笔记 Notes
- 相关经文

点击 Strong's 编号、脚注或交叉引用时，研经面板自动切换到对应资源。

### 4.4 搜索

- phrase、multiword、regex 三种文本搜索
- 大小写敏感选项
- 选择要搜索的模块；搜索结果使用独立的模块实例，不移动阅读器位置
- 范围：整个模块、旧约、新约、当前书卷、当前章节
- 属性搜索，例如 `Word/Lemma=G26`
- 搜索异步执行，带进度、取消和结果计数；失败或取消时保留上一轮结果
- 持久化倒排索引；状态栏说明当前查询是否使用索引，可建立/删除所选模块的索引
- 最近搜索历史
- 结果预览中的匹配词高亮、结果跳转
- 搜索结果支持右键菜单和行尾 `⋯` 操作入口：复制经文/引用/两者、在阅读页或对照页打开、添加笔记、加入背经复习、加入经文列表、查看模块信息

### 4.5 笔记与个人内容

- 个人中心：今日、笔记、祷告、计划、收藏与列表
- 个人注释
- 逐节笔记
- 日记/灵修笔记
- 经文列表与星标收藏：列表管理、阅读器一键星标、收藏列表不可删除
- 书签：阅读位置、标题和备注，与阅读历史分离
- 收获：自由文本、可选经文关联、标签、搜索和更新时间排序
- 祷告事项：进行中、已应允、已归档、搜索、筛选、关联经文和祷告日志
- 主题标签
- 经文高亮
- 经文列表（用户自定义的经文集合，不等同于书签或收藏）
- 笔记搜索、标签筛选和按更新时间排序
- 笔记自动保存、未保存状态提示和删除确认
- 笔记编辑时显示对应经文的单节预览
- Markdown 源文本编辑、基础格式工具栏和语法高亮
- 从预览直接跳回阅读器
- 经文列表增删、列表经文选择和移除；阅读器工具栏可直接把当前经文加入/移出列表
- 书签保存阅读位置；星标收藏是系统默认经文集合；普通经文列表用于自定义分组
- 祷告、书签、收藏、收获及个人中心的整体界面规划见
  [`personal-prayer-design.md`](personal-prayer-design.md)
- 导出 Markdown/HTML

存储策略：

- 个人注释：RawFiles / Personal Commentary
- 日记、祷告列表、通用笔记：RawGenBook
- 阅读计划、计划进度、背经队列、教学讲义：SQLite `app.db`
- 标签、工作区、界面状态：SQLite / GSettings

优先使用 SWORD 兼容格式，使笔记可被其他 SWORD 应用读取。

### 4.6 模块库与安装

- 已安装 / 可安装 / 更新三视图
- 基于 GtkListView 的模块列表，使用过滤和排序模型，支持按名称/类型/语言/状态排序
- 无结果和未安装模块时显示独立空状态
- 已安装模块列表，支持查看本地详情和移除
- 安装源管理：查看、添加、移除来源；支持用户名/密码和连接测试
- 应用级 HTTP 代理设置，留空时沿用环境代理
- 远程列表刷新；全部更新及剩余更新队列；失败项重试和暂停/继续
- 安装前磁盘空间检查
- 加密模块解锁（CipherKey）
- 读取 Requires/Conflicts 配置并显示依赖/冲突提示
- 本地目录选择器和本地模块安装
- 已安装、可更新、未安装状态
- 按名称、语言、类型、授权过滤
- 模块详情：
  - 描述、版本、大小、语言、授权
  - 模块类型
  - 安装状态
  - 依赖/冲突
- 下载进度、速度、剩余时间、取消
- 安装完成后刷新模块库
- 删除模块前确认
- 本地目录安装

### 4.7 阅读计划与灵修

- 每日灵修模块
- 读经计划仪表盘：当前计划、今日阅读、进度条、连续天数和计划完成状态
- 计划模板（90 天新约、30 天诗篇）和自定义计划
- 计划库：计划列表、重命名、复制、删除
- 创建计划使用独立对话框，表单包含名称、起始经文、天数、每日章数，并预览首日和最后一日安排
- “你的计划”标题栏提供常驻“创建计划”按钮，不再在页面底部展开表单
- 日程筛选（全部/未完成/已完成）、今日高亮和跳到今天
- 日程中的书卷名称跟随界面语言本地化
- 今日完成后可撤销
- 提醒设置

### 4.8 背经与复习

可选功能：

- 经文卡片
- 遮盖单词
- 首字母提示
- 间隔重复
- 每日复习队列
- 输入测验
- 希腊文/希伯来文键盘输入

### 4.9 导出与打印

- 复制经文和出处
- 纯文本、HTML、Markdown
- 导出搜索结果
- 打印当前 passage
- 导出笔记

## 6. 主界面设计

### 6.1 主窗口

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 阅读  对照  个人                          [搜索] [模块库] [菜单]│
├──────────────┬─────────────────────────────────────┬─────────────────┤
│ 书卷导航      │  Genesis 1:1                        │ 研经面板         │
│              │                                     │                 │
│ 旧约          │  1 起初，神创造天地。                │ [注释][词典]     │
│  ˅ 创世记     │  2 地是空虚混沌...                   │ [原文][笔记]     │
│  ˅ 出埃及记   │  3 神说：要有光...                   │                 │
│  ˅ 利未记     │                                     │ 当前经文注释     │
│              │                                     │ ...             │
│ 新约          │                                     │                 │
│  ˅ 马太福音   │                                     │                 │
│  ˅ 马可福音   │                                     │                 │
├──────────────┴─────────────────────────────────────┴─────────────────┤
│ KJV ▾  |  创世记 1:1  |  索引: 已建立  |  阅读计划: 第 12 天          │
└──────────────────────────────────────────────────────────────────────┘
```

推荐 GTK4 组件：

- `AdwApplicationWindow`
- `AdwToolbarView`
- `AdwHeaderBar`
- `AdwViewStack`
- `AdwViewSwitcher`
- `AdwViewSwitcherBar` + `AdwBreakpoint`（窄窗口底部导航）
- `AdwOverlaySplitView`（可隐藏/覆盖式模块侧栏）
- `AdwToastOverlay`
- `GtkPaned`
- `GtkListView`
- `GtkPopover`
- `WebKitWebView` 作为经文渲染区

主导航采用单行标题栏布局：宽窗口在 `AdwHeaderBar` 中显示
`AdwViewSwitcher`。窗口最小宽度为 1140px，只支持宽屏桌面；底部
`AdwViewSwitcherBar` 仅保留为窗口管理器强制缩小时的降级路径，不属于验收目标。
模块侧栏与内容区都从标题栏下方开始。

搜索不再是顶层导航项，而是标题栏右侧的搜索按钮和 `Ctrl+F` 动作；搜索页
仍保留完整搜索界面和索引管理，并提供返回按钮。

主导航现为“阅读 / 对照 / 个人”。个人中心使用二级导航：
今日、笔记、祷告、计划、收藏与列表；计划、灵修、背经、祷告、收藏和书签
统一进入个人中心，不再增加主导航项。完整规划与实施记录见
[`personal-prayer-design.md`](personal-prayer-design.md)。

模块库同样不占用主导航项，而是通过标题栏模块库按钮、模块侧栏底部“管理模块”
入口、主菜单或 `Ctrl+Shift+I` 打开；页面提供返回按钮回到打开前的页面。

模块侧栏使用 `AdwOverlaySplitView`。宽窗口下可通过标题栏左侧按钮或 `F9`
隐藏/显示；隐藏后内容占满宽度。窄窗口下侧栏变为覆盖层，默认关闭，选择模块
后自动收起。宽窗口的侧栏可见状态由 `sidebar-visible` GSettings 键保存。

### 6.2 阅读工作区

```text
┌────────────────────────────────────────────────────────────┐
│ [KJV ▾]  [Gen 1:1 ▾]  ← →   [同步]   [布局]               │
├────────────────────────────────────────────────────────────┤
│ Genesis 1                                                  │
│                                                            │
│ 1  起初，神创造天地。                                      │
│ 2  地是空虚混沌，渊面黑暗；神的灵运行在水面上。            │
│ 3  神说：“要有光”，就有了光。                              │
└────────────────────────────────────────────────────────────┘
```

交互：

- 单击经文：选中当前经文
- Shift+单击：选择连续经节范围
- 拖选/双击/三击：正常选择文字，可配合 `Ctrl+C` 或右键复制
- 工具栏复制：优先复制文字选择，其次复制选中经节，否则复制当前节；整章复制放在“更多”菜单
- 工具栏“更多”菜单：复制本章、高亮经节、教学布局
- 工具栏“阅读外观”菜单：字体大小、段落间距、阅读宽度
- 研经面板默认折叠，可拖动分隔条调整宽度，宽度和可见状态会保存
- 研经面板无注释模块时提供“管理模块”入口
- 右键经文：复制当前节、打开笔记、切换高亮
- `F11` 或 `Ctrl+Shift+F`：进入/退出专注阅读模式；专注模式隐藏模块侧栏、研经面板和次要工具栏操作
- 首次运行且未安装模块时：阅读页显示“管理模块”入口，模块侧栏显示空状态，对照页保持空状态且不会生成无模块对照栏

后续可继续补充：

- 双击经文：打开注释/词典面板
- 经文右键菜单继续增加加入列表、搜索相似经文、查看原文
- 点击 Strong's：打开字典
- 点击脚注/交叉引用：打开对应资源

```text
│ Genesis 1:1                                                   │
│ God is **love**                                               │
│ Genesis 1:3                                                   │
│ **love** your neighbour                                       │
└──────────────────────────────────────────────────────────────┘
```

搜索页是内部页面，由标题栏搜索按钮或 `Ctrl+F` 打开，返回按钮回到打开前的
页面。候选模块来自模块库，打开搜索页时默认选中当前阅读模块；范围以当前阅读
位置为基准。索引仅用于不区分大小写、
未限定范围且未启用属性过滤的 phrase/multiword 查询；其他查询自动回退到扫描，
状态行会明确说明。最近搜索保存在当前会话内，可从搜索框右侧的历史按钮重新执行。

### 6.6 笔记与标签

```text
┌──────────────────────────────────────────────────────────────┐
│ 笔记 | 标签 | 经文列表                                        │
├────────────────────────┬─────────────────────────────────────┤
│ 搜索笔记               │ 创世记 1:1               已保存      │
│ 创世记 1:1             │ TinySearch · 创世记 1:1  在阅读器中打开│
│ God is love...         │                                     │
│ 救恩, 神的爱  11-03    │ God is love                         │
│ 创世记 1:2             │                                     │
│ 神创造世界...          │ 标签：救恩, 神的爱        [+]        │
│                        │                                     │
│                        │ Markdown 编辑器                     │
│                        │                                     │
│                        │ [保存] [删除] [加入列表 ▾] [导出]    │
└────────────────────────┴─────────────────────────────────────┘
```

左侧用分页代替纵向堆叠，避免笔记、标签、列表和列表经文互相挤压：

- **笔记**：搜索、标签筛选、笔记列表；显示经文引用、两行预览、标签和更新时间。
- 笔记、祷告、计划等个人内容统一位于个人中心；阅读器“更多”菜单可将当前
  经文添加到祷告草稿。
- 笔记页外层提供“笔记 / 收获”两个标签。收获支持自由文本、逗号分隔标签、
  标签筛选、搜索、更新时间排序和可选经文关联；收获编辑器可直接加入当前经文。
- 收藏与列表提供“经文列表 / 书签 / 星标收藏”三个独立标签，并记住最后一次
  打开的标签；星标收藏是系统列表，不参与普通列表的重命名和删除。
- **标签**：单击标签会设置筛选并保持当前标签页，选中的标签以强调色显示，右侧箭头可查看筛选后的笔记；无需离开标签页即可重命名或删除当前标签。当前标签会显示在笔记页标题（`笔记 · 标签名`）和筛选条中，筛选条提供“全部笔记”；再次单击同一标签、点击“全部笔记”或按 `Esc` 可取消筛选。通过标签菜单显式添加到当前笔记。
- **经文列表**：列表名称与列表经文分成上下两个区域；可选中列表经文后打开或移除。
- 编辑区在停止输入约 1 秒后自动保存，并显示“已保存 / 有未保存的更改 / 未保存”。
- “加入列表”显示带勾选框的列表菜单；阅读器工具栏也提供同样的当前经文列表菜单。

类型、语言、安装状态和文本搜索可以组合使用，只显示同时满足所有条件
的模块；筛选行右侧显示当前结果数量。语言选项根据当前安装源动态生成，

About 使用独立折叠区，避免技术信息挤占主要阅读空间。

安装过程中显示进度、速度、剩余时间、取消按钮，完成后用 toast 提示。

## 7. 响应式与无障碍

### 宽屏

```text
侧栏 + 阅读区 + 研经面板
```

### 中等宽度

```text
侧栏 + 阅读区
研经面板折叠为侧页
```

### 窄屏/平板（不作为支持目标）

项目明确只支持宽屏桌面。窗口最小宽度为 1140px，不提供窄屏/平板布局验收；
`AdwOverlaySplitView` 的 collapsed 状态只作为窗口管理器强制缩小时的降级行为。

无障碍要求：

- 完整键盘操作
- 屏幕阅读器标签
- 高对比度模式
- 可调字体大小、行距、阅读宽度
- RTL 支持
- 本地化书名和缩写
- 经文原文语言字体回退

## 10. 状态与数据存储

```text
~/.local/share/gsword/
  ├── library/                  可写的 SWORD 模块库
  │   ├── mods.d/               模块配置
  │   └── modules/              模块数据
  ├── app.db                    SQLite：笔记、计划、背经、教学讲义
  └── exports/                  导出文件

~/.config/gsword/
  └── installmgr/
      └── InstallMgr.conf       安装源、代理等配置

~/.cache/gsword/
  ├── installmgr/               下载缓存和远端模块列表
  └── search/                   搜索索引
```

系统模块库只读加载：

```text
/usr/share/sword
/usr/local/share/sword
```

用户库优先于系统库；安装、更新和删除只作用于用户库。`~/.sword` 不再作为
默认路径，需要时通过 `--library` 或 `GSWORD_LIBRARY` 显式指定。

原则：

- 模块内容不复制到应用数据库；
- 笔记优先写入 SWORD 兼容模块；
- 标签、工作区、界面状态属于应用私有数据；
- 设置使用 GSettings；
- 配置、缓存、用户数据按 XDG 目录分离；
- 写操作异步执行，避免阻塞 UI。

## 12. 验收标准

- 冷启动后 3 秒内显示可读经文；
- 10 万条以上搜索可通过索引在可接受时间内完成；
- 并行阅读 2–4 个模块时滚动和跳转保持同步；
- 笔记写入失败不破坏既有模块和笔记；
- 模块安装支持进度、取消和失败清理；
- 键盘可完成阅读、搜索、跳转、笔记和安装主流程；
- 宽屏桌面下可完成阅读和搜索；窄窗口不作为验收目标；
- 中英文界面和本地化书名/缩写正常显示。
